# README

*The detailed SAMOD documentation of the ontology is currently upgraded with additionnal content, schemas, examples and a french translation (June 2026)*

## Base namespaces
This folder contains the SAMOD documentation of the TABULAE ontology, which is an extension of the PeGazUs ontology.
The TABULAE ontology is dedicated to the representation of land plots evolution using assertions extracted from (historical) documents.
```
<https://w3id.org/tabulae>
```

The following URI is the one of the PeGazUs ontology which is extented by TABULAE.
```
<https://w3id.org/PeGazUs#>
```

## Used vocabularies
Following the recommandations of the W3C, this ontology reused concepts and properties of several pre-existant ontologies. It is also and extension of the PeGazUs ontology.
* PeGazUs
* Prov-O
* RiC-O
* Time
* DCTerms

## Files
* ```ontology.ttl``` contains the implementation of the ontology without the skos concepts instances. We 
* ```ontology-with-skos.ttl``` contains the implementation of the ontology plus the different skos concepts. This file is automatically generated using the `ontology.ttl` file and the SKOS Concept instances inmplemented in the `data\skos\ttl` folder.

## Methodology for ontology developpement
* Manually developped following the SAMOD methodology.
* Ontology consistency has been validated in Protégé with HermiT reasonner and with Ooops!. Additionnal review has been done with Ask WOL in the end of 2026.
* Annotation properties have been checked with Mentor.
* Online documentation is generated with Widoco and supplemented with extra content (including charts for thesaurus understanding).
* By the end of 2026, an additionnal review has been performed with Claude Opus 5.5. Every ontology update and implementation choices are the one of the authors !

## Codes namespaces
Some of the SKOS concept have French names because they have been specificaly developped using the French Land Registry (both historical and modern). When they have equivalent names in english, they are provided using skos:PrefLabel@en.
